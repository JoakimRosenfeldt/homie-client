Independent review and repairs

Findings stayed separated by review axis.

  • Standards

    Accessibility and platform behavior

    Reviewers found missing React Native Web ARIA state, incomplete composite keyboard behavior, heading-level drift, weak form-error focus, button-shaped navigation, and modal focus gaps.

    • Added direct aria-checked, aria-selected, progress values, labelled radio groups, Space/arrow handling, and roving tab focus.
    • Added heading levels, field-linked errors, first-invalid-field focus, visible focus rings, keyboard-safe scrolling, and Link-backed destination controls.
    • Added modal focus capture, trap, Escape handling, background inert state, and trigger restoration on web.
  • Product spec

    End-to-end behavior and truthful states

    Reviewers found identity-dependent browsing, cold-offline loading loops, unreachable saved-search notifications, missing profile-photo management, partial i18n, misleading Explore paging, and stale draft routing.

    • Public Explore now works without private identity; private actions degrade independently and cold-offline states are explicit.
    • Saved-search notification opt-in is editable and tied to real token availability; shared-home photos upload, persist, reorder safely, and render to authorized hosts.
    • Core seeker, host, listing, report, and deletion flows use typed EN/DA copy and locale-aware dates, currency, counts, and retry times.
    • Explore uses a maintained search projection with global filtering and ordering, keyset paging, exact counts within capacity, and honest map truncation.
  • Convex

    Security, ownership, scheduling, and invariants

    The first backend audit found a critical cross-tenant storage deletion path plus push, privacy, blocking, validation, and query-correctness issues.

    • Owner-bound, one-time upload sessions now gate attach and deletion. Public and host views expose URLs, never reusable raw storage IDs.
    • Push work uses leases, exponential due-time retries, recovery cron, ticket and receipt handling, opt-out/tombstone revalidation, dedupe, and cleanup.
    • Applications and conversations carry safe listing snapshots; block direction, mutual state, and canSend are explicit.
    • Deletion redacts the requester while preserving shared records; reports have target-checked moderation transitions; writes use bounded validation and rolling limits.

Before distribution

External gates and honest residuals

  • Configuration

    Push, moderation, geocoding

    Set a real EAS project ID and APNs/FCM credentials, configure MODERATION_SECRET, and confirm the selected geocoding provider’s production policy.

  • Physical QA

    Native devices and assistive technology

    Run the planned iOS and Android matrix: VoiceOver, TalkBack, 200% text, safe areas, reduced motion, location denial, map movement, push delivery, and the complete application-to-chat flow.

  • Architecture

    Anonymous bearer identity

    Device secrets are strong bearer keys, not attestation. A determined caller can mint another identity and reset device-keyed limits. Accounts, attestation, or an external abuse layer are needed for stronger Sybil resistance.

  • Scale and migration

    Fail closed, never lie

    Explore fails explicitly above the 5,000-row reactive search capacity. Unlimited arbitrary text, viewport, and distance search needs async search sessions or a search service. Legacy untracked blobs are detached, not deleted, because ownership cannot be proven.

  • Operations

    Upload loss edge case

    Known upload failures use discard mutations. If a client loses both the storage and session IDs after a successful upload, Convex storage metadata cannot reconstruct that association automatically.

  • Sign-off

    Legal and distribution

    Complete legal/privacy review, moderation operator testing, signed development-build QA, and internal distribution setup before inviting beta users.
